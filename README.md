# Mobile-app-for-tourists
Mobile app for tourists [Java/Android/SQL]

!!! App is in master branch, not main !!!

This project has been done by 1 student from University of Novi Sad, Faculty of Mathematics.

Its done as a project for univeristy.

It presents mobile app for tourists.

It's done in Android studio using Java, database in done in SQLite(Room) and SharedPrefference.

Project has all validations and Exception handlers needed.

Project has MVVM architecure.

CRUD operations includes with database.

Project has two layouts: one for mobiles and other for tablets.

Features:
- Java
- Android
- SQLite (Room)
- Weather API (open-meteo.com API)
- Map API (OSRM API)
- Shared Prefference
- RecycleView
- Spinner
- Layout for mobile phones and tablets
